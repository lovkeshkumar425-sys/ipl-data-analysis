# IPL Data Analysis | Power BI Dashboard

## 📌 About the Project
This project presents an interactive Power BI dashboard for analyzing Indian Premier League (IPL) data. The dashboard helps explore team performance, match results, player statistics, and other important trends across IPL seasons.

## 🛠️ Tools Used
- **Power BI** — Data visualization and interactive dashboard
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures and calculations

## 📊 Dashboard Insights
- IPL match and season analysis
- Team performance comparison
- Match results and winning trends
- Player performance analysis
- Toss decisions and match outcomes
- Interactive filtering and data exploration

To explore IPL data through interactive visualizations and make team, player, and match performance easier to understand.

## 💡 Key Learnings
- Building interactive dashboards in Power BI
- Cleaning and transforming data using Power Query
- Creating measures using DAX
- Comparing performance and identifying trends through visualizations
